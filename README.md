# 飛行棋遊戲

## Project Overview
This is a flying chess game developed with React, offering single-player gameplay against an AI opponent that utilizes the Monte Carlo Tree Search (MCTS) algorithm.

## Installation Steps
1. Ensure Node.js is installed (recommended version 16 or above)
2. Clone the project locally:
   ```bash
   git clone https://github.com/your-repo/flying-chess.git
   cd flying-chess
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
5. Open your browser and visit http://localhost:5173 to start playing
